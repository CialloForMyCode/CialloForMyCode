## 正在产出

### ONC Compiler Collection

ONC (ONC's Not C#) 是一门面向对象的计算机语言，它是一门可以直接使用C#/Java风格语句进行裸机开发的通用计算机编程语言。该编程语言以我也不知道这玩意有什么用，就是我脑子一热做出来的。
ONC在裸机环境中几乎无依赖，ONC可以在没有运行时的情况下编译出不可变代码。

#### 当前进度
- [x] 基本编译器词典
- [x] IR -> AST
- [x] 运行时
- [x] GC
- [x] 泛型系统
- [x] P/Invoke (基本完成，不保证完全可用)
- [x] x86_16 裸机环境下的代码生产
- [ ] x86_32 / x64 裸机环境下的代码生产
- [x] x86_32 / x64 Windows 环境的代码生产 (部分完成，不保证完全可用)
- [ ] Linux 环境下的代码生产
- [ ] 其他嵌入式环境下的代码生产
- [ ] 基类库 (部分完成，大部分不可用)
