## 关于我

> I am so solo, talk to me please.

我写的工具都是我自己每天在用的。它们大多起于同一件事：某个流程痛到一定程度，自动化它比重复它更划算。

我的技术栈是 **C# / .NET 8**，在 Windows 上主要用 **WPF**；凡是需要被脚本、CI 或 AI 驱动的场合，都会附一个输出标准 JSON 的 CLI。

## 我的做法

- **整条链路自己写。** OCC 不带任何第三方 NuGet 依赖 —— 需要什么就自己写。
- **两个入口。** 给人用的图形界面，给机器用的标准 JSON 命令行。
- **文档多语言。** 每个项目的 README 都有 6 种语言，顶部带语言切换。
- **朴素、居中、零 emoji 的 README。** 徽章和表格把话说清楚。
