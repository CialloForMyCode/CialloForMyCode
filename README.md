## About

> I am so solo, talk to me please.

I write tools that I actually use every day. They almost always start the same way: some workflow of mine gets painful enough that automating it becomes cheaper than repeating it.

My stack is **C# / .NET 8**, mostly **WPF** on Windows — plus a CLI with standard JSON output whenever a tool needs to be driven by scripts, CI, or an AI agent.

## Featured project

### OCC's Mission & Goals

An update / patch management tool built for the ONC Compiler Collection. It folds "write the problem down in Markdown, then hunt for the ones I never finished" into a single program — a tool for my workflow, and a treatment for my memory.

## How I work

- **Own the whole stack.** OCC ships with no third-party NuGet dependencies — if something needs doing, it gets written.
- **Two front doors.** A GUI for humans, a CLI with standard JSON for machines.
- **Documentation in many languages.** Every project README ships in 6 languages, with a language switcher at the top.
- **Plain, centered, emoji-free READMEs.** Badges and tables do the talking.
