## Also building

### ONC Compiler Collection

ONC (ONC's Not C#) is an object-oriented computer language — a general-purpose programming language that lets you do bare-metal development with C# / Java style statements. As for what it's good for, I have no idea; I built it on a whim.
ONC has almost no dependencies in bare-metal environments, and it can compile immutable code without a runtime.

#### Current progress
- [x] Basic compiler dictionary
- [x] IR -> AST
- [x] Runtime
- [x] GC
- [x] Generics system
- [x] P/Invoke (mostly done, not guaranteed to fully work)
- [x] Code generation for the x86_16 bare-metal environment
- [x] Code generation for the x86_32 / x64 bare-metal environments
- [x] Code generation for x86_32 / x64 Windows (partly done, not guaranteed to fully work)
- [ ] Code generation for Linux
- [ ] Code generation for other embedded environments
- [ ] Base class library (partly done, mostly unusable)
- [x] Math library
- [ ] WinAPI library (partly done, mostly unusable)
